按钮块示例
按钮块把思源原生样式的按钮放进文档里，点击即可跳转链接或运行 JavaScript。
在文档里输入 /按钮块 回车即可插入，块内容本身是一段纯 JSON，只有插件启用时才会渲染成按钮。
点击块图标打开块菜单，插件 > 编辑按钮块 可以修改按钮文本、图标与操作。
按钮的宽度、字号、圆角、悬浮与按下效果都来自思源自身的样式，与设置面板里的按钮完全一致。
按钮图标从当前界面可用的 SVG 图标里选，也可以不设置图标。
链接跳转支持任意写法：http(s)、siyuan://blocks/<块 ID>、assets/<资源路径>、mailto: 以及系统注册的其他协议。
JavaScript 操作在页面上下文里执行，能力与思源的 JavaScript 代码片段一致，支持 await。
代码编辑器带行号、语法高亮与补全，配色跟随「设置 - 外观 - 代码高亮」里选择的方案。
只有光标位于按钮块上时，块菜单里才会出现 插件 > 编辑按钮块，其他块不受影响。
移动端同样可以插入与编辑按钮块，界面结构与桌面端一致。
发布服务上本插件被禁用，发布页面显示的是按钮块的原始 JSON 内容。
